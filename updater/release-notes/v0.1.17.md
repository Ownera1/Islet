# Islet 0.1.17

- Agent 面板：审批或选项问题回答完后（无论在刘海里、Claude Code 还是 Claude 桌面版中作答），弹出的 Agent 状态页会自动收起；指针停在刘海上时，移开后再收起。
- Agent 审批快捷键：有待处理的审批时，按 ⌃⌥Y 允许、⌃⌥N 拒绝（选项问题按 ⌃⌥N 取消）。仅在有待处理请求时生效，其余时间不占用按键；可在「设置 → 快捷键 → Agent」中修改。

提供 Apple Silicon 与 Intel 通用 DMG／ZIP；自动更新使用 Sparkle Ed25519 签名。应用沿用 ad-hoc 签名，未经过 Apple 公证。
