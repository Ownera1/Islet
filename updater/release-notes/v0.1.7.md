# Islet 0.1.7

本次最终更新包含显示器、HUD、Agent 页与收起态歌词修改。

- 修复自动切换显示器开关仅改变透明度的问题：首选屏断开时回退，重连后恢复；屏幕布局变化会重新定位。
- HUD 权限检查与媒体键拦截统一由 Helper 处理，并启用 NSRunLoop 来分发媒体键事件。开启失败和连接中断显示明确提示，保留音量、亮度、背光与修饰键操作。
- Agent 页新增全部总览、状态分组下拉菜单和持久化的单行／双行样式。框架名称完整显示，保留多会话、任务、审批和回答。
- 收起态歌词新增仅外接屏／所有显示器选项，支持当前句高亮、长句滚动、间奏、暂停和减少动态效果。
- 主应用与 Helper 均移除调试权限；发布校验同时检查权限与 Helper 运行配置。

推荐安装此版本。提供 Apple Silicon 与 Intel 通用 DMG／ZIP；自动更新继续使用原有 Sparkle Ed25519 公钥。应用沿用 ad-hoc 签名，未经过 Apple 公证。
