## 0.1.3

- 应用与仓库更名为 Islet，菜单、引导页、设置、安装包和更新链接保持一致；已有设置与 Agent 连接继续使用。
- 修复歌词专注模式展开时顶部露出系统栏缝隙的问题，展开背景统一定高、顶部对齐并裁剪。
- 更新接入 Sparkle：自动检查，应用内下载、签名验证、安装和重新启动；设置中可开启后台下载。
- Home 音乐播放器调整封面、标题、歌手、进度和控制按钮的比例，显示当前歌词与下一句预告。
- 增加歌词专注模式，保留日历状态并显示可滚动、可点击跳转的歌词。
- 增加逐字歌词与增强 LRC 解析、行级扫光降级、长句滚动和歌词时间偏移设置。
- 改善加载中、纯音乐与缺失歌词状态，歌词异步到达不再推动播放控制的位置。

需要 macOS 15 或更新版本，支持 Apple Silicon 和 Intel。0.1.2 及更早版本需手动安装一次；从本版本开始支持应用内更新。

下载 DMG，将 Islet.app 拖入 Applications。手动迁移时先退出旧应用，移除旧 Agent Usage Notch.app，已有设置会保留。发行包使用本地代码签名和 Ed25519 更新签名，尚未经过 Apple 公证。
