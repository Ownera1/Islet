# Islet 0.1.14

Agent 卡片的「打开来源窗口」和「前往处理」可以直接跳到对应会话。

- Claude 桌面版 Code 标签页：直接切换到该会话，不再只是打开桌面版。
- Ghostty：切换到会话所在目录的终端；同一目录开了多个终端时，优先选择标题包含会话标题的那个。首次使用时 macOS 会询问是否允许 Islet 控制 Ghostty。
- 设置中移除了从未生效的「左右轻扫切换歌曲」开关。

提供 Apple Silicon 与 Intel 通用 DMG／ZIP；自动更新使用 Sparkle Ed25519 签名。应用沿用 ad-hoc 签名，未经过 Apple 公证。
