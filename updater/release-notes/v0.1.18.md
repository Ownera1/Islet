# Islet 0.1.18

- 网易云音乐「喜欢」同步：播放网易云音乐时，点歌曲页的爱心会直接喜欢／取消喜欢当前歌曲，爱心状态也会随网易云更新。首次使用需在「系统设置 → 隐私与安全性 → 辅助功能」中允许 Islet。
- Apple Music 的爱心按钮修复：选择 Apple Music 作为音乐来源时，点击爱心现在能正确收藏歌曲；使用「系统正在播放」时，切歌后爱心状态会跟着刷新。
- Agent 状态页支持数学公式：回复中的 `$…$`（行内）和 `$$…$$`（独立公式）会排版显示，价格之类的 `$5` 仍按普通文字显示。
- 修复「媒体」设置中「系统正在播放」偶尔消失、只剩 Apple Music／Spotify／YouTube Music，且需重启才恢复的问题。

提供 Apple Silicon 与 Intel 通用 DMG／ZIP；自动更新使用 Sparkle Ed25519 签名。应用沿用 ad-hoc 签名，未经过 Apple 公证。
