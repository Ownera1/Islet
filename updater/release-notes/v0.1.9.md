# Islet 0.1.9

新增 Claude 桌面版支持。

- Claude 桌面版 Code 标签页的会话显示在刘海中，卡片标注「Claude 桌面版」，点击回到桌面版。审批可以直接在刘海中允许或拒绝；在桌面版自己的卡片中处理后，刘海的审批卡会在该工具运行结束时自动移除。
- 显示 Claude 桌面版 Cowork 任务的运行、等待审批和完成状态（只读读取桌面版的会话记录；审批需在桌面版中处理），点击打开对应任务。
- Claude 订阅额度按所配置的 Claude 目录查找对应的命令行版登录。只用桌面版时，卡片会提示在终端运行一次 `claude` 登录后即可显示实时额度。
- bridge 只在设置 `BORINGNOTCH_DEBUG=1` 时写调试日志，且不记录 Hook 内容。

提供 Apple Silicon 与 Intel 通用 DMG／ZIP；自动更新使用 Sparkle Ed25519 签名。应用沿用 ad-hoc 签名，未经过 Apple 公证。
