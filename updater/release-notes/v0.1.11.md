# Islet 0.1.11

修复 Codex 桌面版会话跳转到终端的问题。

- 在 Agent 详情页点击 Codex 桌面版会话的跳转按钮，现在会打开 Codex 桌面版中对应的对话，而不是终端。新版 Codex 桌面版（ChatGPT.app）不再向 hook 传递应用标识，导致桌面会话被误认为命令行会话。
- Codex 的 SessionEnd 和 Interrupt hook 超时改为官方上限 3 秒（原为 5 秒）。
- 修正 ZCode 桌面版的应用标识，跳转时直接按标识打开 ZCode。

更新后请到「设置 → Agent 与订阅」中关闭再重新开启 Codex 集成，以安装新的桥接程序和 hook 配置；更新前已存在的 Codex 桌面会话卡片不会自动纠正，新会话即可正常跳转。

提供 Apple Silicon 与 Intel 通用 DMG／ZIP；自动更新使用 Sparkle Ed25519 签名。应用沿用 ad-hoc 签名，未经过 Apple 公证。
