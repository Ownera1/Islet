# Islet 0.1.6

包含 0.1.5 的显示器切换、HUD、Agent 总览与收起态歌词更新，并完善最终安装包的签名校验。

- 清除 Xcode 自动注入到 Helper 的调试权限。Release 构建关闭开发权限注入，打包时同时清理主应用和 Helper，并独立校验二者。
- 自动切换显示器支持首选屏断开后回退、重连后恢复；HUD 权限检查和媒体键拦截统一由 Helper 处理。
- Agent 页提供全部总览、状态分组下拉菜单和单行／双行设置，框架名称完整显示，保留多会话、任务、审批和回答。
- 收起态歌词提供外接屏／所有显示器选项，以及当前句高亮、长句滚动、间奏、暂停和减少动态效果。

提供 Apple Silicon 与 Intel 通用 DMG／ZIP，推荐安装此版本。自动更新继续使用原有 Sparkle Ed25519 公钥；应用沿用 ad-hoc 签名，未经过 Apple 公证。
