# Islet 0.1.10

刘海跟随指针切换显示器，外接显示器亮度可直接调节，设置界面全面汉化。

- 开启「刘海跟随指针切换显示器」后，刘海会移到指针停留的显示器上；刘海展开、拖放文件或显示提示时不切换。关闭后刘海固定在首选显示器，首选显示器断开时回退，重新连接后恢复。
- 亮度键调节指针所在的显示器：内置屏和 Apple 显示器使用系统接口，其他外接显示器通过 DDC/CI 调节（Apple 芯片），亮度提示显示在刘海中；不支持的显示器交给系统处理。如果 BetterDisplay 等工具也接管了亮度键，建议在其中关闭，避免两个应用争抢按键。
- 修复 HUD 开关显示开启却没有接管音量和亮度键的问题。现在 HUD 开启时会定时检查按键拦截，丢失后自动恢复；无法恢复时关闭开关并提示原因。
- Agent 对话完成后展开的状态页会按设置的时间自动收起（设置 → Agent 与订阅 → 自动收起，默认 5 秒）；指针停在刘海上时保持展开，等待审批或回答时不收起。
- 设置界面全部改为中文，并为含义不清的选项换了更直白的名称。
- 修复退出 Islet 后，读取播放信息的后台进程残留的问题。

更新后如果 HUD 开关被自动关闭，请到「系统设置 → 隐私与安全性 → 辅助功能」中删除旧的 Islet 条目，再在 Islet 设置中重新开启 HUD 并授权。

提供 Apple Silicon 与 Intel 通用 DMG／ZIP；自动更新使用 Sparkle Ed25519 签名。应用沿用 ad-hoc 签名，未经过 Apple 公证。
